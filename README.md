# VYRON Mobile V1

VYRON is the working name for this personal AI assistant prototype.

Features in V1:
- Mobile-friendly interface
- Voice input (browser support required)
- Voice output
- Local commands: time, date, Google, YouTube
- PWA structure for adding to Android home screen

Next upgrade: connect a secure backend/API for real AI chat, then add vision, memory and Android actions.

Do not put a private AI API key directly into index.html; use a backend to protect it.
